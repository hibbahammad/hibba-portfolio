## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/hibbahammad/hibba-portfolio.git
```

### 2. Open the project

```bash
cd hibba-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown by Vite in your browser.
